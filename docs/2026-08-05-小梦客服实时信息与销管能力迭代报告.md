# 小梦客服：实时信息接口化 + 销管引导 + 工具链路修复（2026-08-05）

> 目标：让系统客服「小梦」不再依赖知识库回答随时变化的关键信息（公告 / 更新日志 / 会员价格 / 店铺数量限制 / 功能对比），
> 全部改为实时接口/实时配置查询；同时补齐销管角色并修复工具调用链路中的真实缺陷。

---

## 一、需求与实现对照

| # | 需求 | 实现 |
