## 二、发布前置条件（阻塞项，缺一不可）

1. **干净已提交工作区**：当前工作区包含本次迭代与历史滑块/WS 等改动，必须先 commit（建议分两个提交：小梦迭代 + 滑块/WS 迭代），
   部署脚本会拒绝未提交/未跟踪的源码树。
2. **迁移证据**：按 `docs/database-migrations.md` 生成 `migration-evidence.json`（格式 v2）：
   - release ID（如 `release-20260805-xiaomeng-01`）；
   - releaseRevision = 本次发布 commit 的完整 SHA；
   - manifest SHA-256（当前：`d635e4ec198b0f25dda69d0d527cdc3ab799c5afffb451fbf644a0cbed0b5ed3`）；
   - 审批身份 + 变更单号；
   - 三个数据库（core_mysql / automation_mysql / crawler_postgres）<24h 的备份 artifact ID + SHA-256；
   - 三个数据库 <90 天内的恢复演练记录；
   - 有效期 ≤24h。
3. **备份与恢复演练**：由运维在独立环境完成；禁止把恢复演练指向唯一生产卷。
4. **监控就绪**：Prometheus/Grafana/Alertmanager/blackbox 健康且告警可达（部署脚本会 fail-closed 检查）。
5. **维护窗口**：本拓扑为原地址重建，非零停机；后端发布会有短暂中断。

## 三、迁移执行计划（core_mysql）

按 `database-migrations.md` 流程：

1. 冻结发布 commit，`python scripts/validate_migrations.py` 记录 manifest SHA-256；
2. 生产备份 → 隔离演练环境；
3. 数值顺序演练 V1.70 → V1.71 → V1.72 → V1.73（均为幂等/可重入）；
4. 演练关键链路：登录、账号/消息、订单、发货、计费、定时任务、AI 客服（小梦）；
5. 恢复演练：备份恢复到独立目标并重跑上述检查；
6. 正式窗口：停写/排空 → 新备份 + 校验 → 应用迁移（`SCHEMA_RUNTIME_MUTATIONS_ENABLED=false` 前提下由 DBA 执行）→ 验证 → 部署。

各迁移幂等性说明：
- V1.70：UPDATE + INSERT ... WHERE NOT EXISTS；
- V1.71：INFORMATION_SCHEMA + PREPARE/EXECUTE 动态 SQL；
- V1.72：CREATE TABLE IF NOT EXISTS + 列存在性检查 + UPDATE/INSERT；
- V1.73：UPDATE（幂等）。

## 五、上线后验证清单

### 平台冒烟（部署脚本自动）
- 用户/管理端健康、登录、受保护接口 token 校验。

### 小梦专项验收

1. 新会话欢迎语：应包含「和我对话由系统额度承担，不扣您的 Token」与四档会员（普通/VIP（单店版）/VIP/SVP）。
2. 实时信息：
   - 「会员多少钱？」→ 调 `get_vip_price`，返回四档实时价格；
   - 「能绑定几个店铺？」→ `get_store_limit`；
   - 「普通和VIP有什么区别？」→ `get_feature_comparison`；
   - 「最近更新了什么？」→ `get_release_notes`（当前 2.5.0）；
   - 「有什么公告？」→ `get_announcements`；
   - 「有什么促销活动？」→ `get_promotions`；
   - 「我的Token余额」→ `get_token_balance`（含等级定价表）。
3. 工具链路：创建卡密分组 → 确认 → 成功；删除 → 拒绝 → 数据库状态 rejected；删除非空分组 → 友好失败。
4. 知识库同步：调用 `POST /api/ai-cs/knowledge/sync-features` 应返回 9 分类 / 36 功能 / 零漂移。
5. 促销接口：`GET /api/promotion/active` 应返回 200（不再 503）；调度器日志无「表不存在」。
6. 审计：`ai_cs_tool_call` 状态分布正常；24h 后过期 pending 清理任务生效（状态 expired）。

### 数据验证
- `billing_plan` 四档套餐价格与店铺限制（normal 1 / vip-single 1 / vip 不限 / svp 不限）；
- `admin_module_record.user_feature_switch` 的 `store-limit` 行存在；
- `ai_cs_knowledge` 中无「三档会员/免费额度/最多 3 个账号」等过期文案。
